# AptosFS Onboarding Tutorials

Welcome to AptosFS! These step-by-step tutorials will help you get started with the AptosFS decentralized file system. Each tutorial focuses on essential tasks to help you become productive quickly.

## Getting Started

### Tutorial 1: Creating Your Account

**Objective:** Set up your AptosFS account and configure basic settings.

**Steps:**

1. **Sign Up**
   - Navigate to [AptosFS.com](https://aptosfs.com)
   - Click the "Sign Up" button in the top-right corner
   - Choose your preferred registration method:
     - Email and password
     - Connect your Aptos wallet
   - Complete the registration form
   - Verify your email address if you signed up with email

2. **Set Up Your Profile**
   - Log in to your new account
   - Click on your profile icon in the top-right corner
   - Select "Profile Settings"
   - Add your profile picture and display name
   - Configure your notification preferences

3. **Choose Your Theme**
   - Go to "Settings" > "Appearance"
   - Select your preferred theme (Light or Dark)
   - Optionally, enable "System Theme" to automatically match your device settings

4. **Secure Your Account**
   - Navigate to "Settings" > "Security"
   - Enable two-factor authentication for additional protection
   - Set up recovery options (backup email, phone number)
   - Review active sessions and devices

### Tutorial 2: Exploring the Interface

**Objective:** Familiarize yourself with the AptosFS user interface.

**Steps:**

1. **Understanding the Layout**
   - **Top Menu Bar:** Global actions, search, and profile settings
   - **Sidebar:** Navigation, favorites, and storage information
   - **Main Content Area:** Files and folders in your current location
   - **Status Bar:** Operation progress and system notifications

2. **Navigation Basics**
   - Click on folders to open them
   - Use the path bar to see your current location and navigate up
   - Use the back and forward buttons to move through your history
   - Try the sidebar shortcuts for quick access to key locations

3. **View Options**
   - Toggle between Grid View and List View using the view selector
   - Try different sorting options (by name, date, size, type)
   - Adjust the thumbnail size using the slider (in Grid View)
   - Try the search function to find specific files

4. **Keyboard Shortcuts**
   - Press F1 to view the full list of keyboard shortcuts
   - Try these essential shortcuts:
     - Ctrl+F (Cmd+F on Mac): Search
     - Ctrl+A (Cmd+A on Mac): Select all items
     - Ctrl+C, Ctrl+X, Ctrl+V (Cmd+C, Cmd+X, Cmd+V on Mac): Copy, cut, paste

## File Management

### Tutorial 3: Uploading Your First Files

**Objective:** Learn different ways to upload files to AptosFS.

**Steps:**

1. **Method 1: Upload Button**
   - Navigate to your desired folder
   - Click the "Upload" button in the toolbar
   - Select one or more files from your device
   - Watch the progress in the status bar

2. **Method 2: Drag and Drop**
   - Open a folder window on your computer
   - Select files or folders you want to upload
   - Drag them into the AptosFS browser window
   - Drop them in the main content area

3. **Method 3: Upload Area**
   - Scroll to the bottom of the main content area
   - Find the "Drop files here to upload" area
   - Click on it or drag files directly to this area
   - If you click, a file picker will open

4. **Handling Large Files**
   - For files larger than 1GB, note the upload progress
   - Uploads can be paused and resumed if needed
   - For very large files, consider using the desktop app
   - Monitor bandwidth usage in the status bar

### Tutorial 4: Creating and Organizing Folders

**Objective:** Create a folder structure to organize your files.

**Steps:**

1. **Creating Folders**
   - Navigate to where you want to create a folder
   - Click the "New" button in the toolbar
   - Select "New Folder"
   - Enter a name for your folder
   - Press Enter or click "Create"

2. **Building a Folder Structure**
   - Create a main folder for your project (e.g., "Work Projects")
   - Open that folder and create subfolders (e.g., "Documents", "Images")
   - Continue nesting folders as needed for organization

3. **Moving Files Between Folders**
   - Select files you want to move
   - Drag them to the destination folder
   - Alternatively, use Cut (Ctrl+X / Cmd+X) and Paste (Ctrl+V / Cmd+V)
   - Watch the operation progress in the status bar

4. **Organizing with Tags**
   - Select a file or multiple files
   - Right-click and select "Tags"
   - Add existing tags or create new ones
   - Use the search filter to find files by tag later

### Tutorial 5: Downloading and Sharing Files

**Objective:** Learn how to download files and share them with others.

**Steps:**

1. **Downloading Files**
   - Select the file(s) you want to download
   - Click the "Download" button in the toolbar
   - Alternatively, right-click and select "Download"
   - Choose a location on your device to save the file(s)
   - For multiple files, they'll be bundled as a ZIP archive

2. **Creating a Share Link**
   - Select the file or folder you want to share
   - Click the "Share" button in the toolbar
   - In the sharing dialog, toggle "Create link"
   - Set permissions (view or edit)
   - Optionally set an expiration date and password

3. **Sharing with Specific People**
   - In the sharing dialog, enter email addresses
   - Set permissions for each recipient
   - Add an optional message
   - Click "Send" to notify recipients

4. **Managing Shared Items**
   - Click "Shared" in the sidebar
   - View items you've shared and their settings
   - Modify permissions or revoke access if needed
   - See access logs for shared files

## Advanced Features

### Tutorial 6: Blockchain Verification

**Objective:** Learn how to verify files on the blockchain for enhanced security.

**Steps:**

1. **Connecting Your Wallet**
   - Click your profile icon in the top-right corner
   - Select "Wallet Settings"
   - Click "Connect Wallet"
   - Choose your Aptos wallet (Petra, Martian, etc.)
   - Approve the connection request in your wallet

2. **Verifying a File**
   - Select a file you want to verify
   - Right-click and select "Verify on Blockchain"
   - Review the transaction details
   - Confirm the transaction in your wallet
   - Wait for blockchain confirmation

3. **Checking Verification Status**
   - Select the verified file
   - Look for the verification badge
   - Click on the badge to view details
   - See timestamp, transaction ID, and verification status

4. **Proving Ownership**
   - For verified files, you can generate a proof of ownership
   - Right-click the file and select "Proof of Ownership"
   - Choose between downloadable certificate or shareable link
   - Use this proof to establish ownership of intellectual property

### Tutorial 7: Using Version History

**Objective:** Learn how to track and manage file versions.

**Steps:**

1. **Viewing Version History**
   - Select a file
   - Right-click and select "Version History"
   - Alternatively, click "More Options" > "Version History"
   - See all previous versions with timestamps and authors

2. **Comparing Versions**
   - In the Version History panel, select two versions
   - Click "Compare"
   - View differences highlighted side by side
   - Switch between different comparison views

3. **Restoring Previous Versions**
   - Find the version you want to restore
   - Click "Restore This Version"
   - Confirm that you want to make this the current version
   - The restored version becomes the new current version

4. **Managing Version Retention**
   - Go to "Settings" > "Storage"
   - Under "Version History", set your retention policy
   - Choose between keeping all versions, limited versions, or time-based retention
   - Apply different policies to different folders if needed

### Tutorial 8: Collaborative Editing

**Objective:** Learn how to collaborate on documents with other users.

**Steps:**

1. **Sharing for Collaboration**
   - Select a file
   - Click "Share" in the toolbar
   - Add collaborators with "Can Edit" permissions
   - Send the invitation

2. **Real-time Collaboration**
   - Open a shared document
   - Multiple users can edit simultaneously
   - See others' cursors and changes in real-time
   - Changes are automatically saved

3. **Using Comments**
   - Select text or an area of the document
   - Click the "Comment" button
   - Type your comment
   - Tag specific users with @ mentions
   - Resolve comments when addressed

4. **Tracking Changes**
   - Enable "Track Changes" mode in compatible documents
   - Make edits that are highlighted as suggested changes
   - Accept or reject changes
   - View edit history with attribution

## Mobile Access

### Tutorial 9: Using AptosFS on Mobile Devices

**Objective:** Access and manage your files on mobile devices.

**Steps:**

1. **Installing the Mobile App**
   - Visit the App Store (iOS) or Google Play Store (Android)
   - Search for "AptosFS"
   - Download and install the app
   - Log in with your account credentials

2. **Mobile Navigation**
   - Use the bottom navigation bar to access key sections
   - Swipe left/right to navigate between folders
   - Pull down to refresh the current view
   - Use the floating action button for common actions

3. **Mobile-Specific Features**
   - Use the camera to scan documents directly into AptosFS
   - Enable automatic photo backup
   - Set up biometric authentication (fingerprint/face)
   - Configure offline access for important files

4. **Syncing Between Devices**
   - Changes made on mobile sync automatically to other devices
   - Monitor sync status in the account menu
   - Manage bandwidth usage in settings
   - Pause syncing when on cellular data if needed

## Integrating with Other Tools

### Tutorial 10: Using the AptosFS API and Integrations

**Objective:** Connect AptosFS with other tools and services.

**Steps:**

1. **Connecting Third-Party Apps**
   - Go to "Settings" > "Connected Apps"
   - Click "Connect New App"
   - Browse available integrations or enter app details
   - Authorize the connection
   - Set appropriate permissions

2. **Creating API Tokens**
   - Navigate to "Settings" > "Developer"
   - Click "Create New API Token"
   - Name your token and set permissions
   - Copy and securely store the generated token
   - Use the token in your API requests

3. **Setting Up Webhooks**
   - In Developer settings, go to "Webhooks"
   - Click "Add Webhook"
   - Enter your endpoint URL
   - Select events to trigger the webhook
   - Test the webhook to verify it's working

4. **Automated Workflows**
   - Go to "Settings" > "Automation"
   - Click "Create New Workflow"
   - Set up triggers (file uploads, sharing, etc.)
   - Define actions to perform
   - Enable and test your workflow

## Tips for Success

Here are some best practices to get the most out of AptosFS:

1. **Regular Organization**
   - Develop a consistent folder structure
   - Use descriptive filenames
   - Apply tags for cross-folder organization
   - Archive older files you don't need frequent access to

2. **Security Habits**
   - Use strong, unique passwords
   - Enable two-factor authentication
   - Review shared files periodically
   - Check access logs for unexpected activity

3. **Performance Optimization**
   - Clear cache periodically
   - Use the desktop app for large file transfers
   - Close unused browser tabs
   - Consider upgrading your plan if you need more storage

4. **Staying Updated**
   - Check the product blog for new features
   - Follow AptosFS on social media
   - Join the community forum for tips
   - Watch tutorial videos for new functionality

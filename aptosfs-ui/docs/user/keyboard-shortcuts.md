## Power User Tips

- Press <kbd>Tab</kbd> repeatedly to navigate through interactive elements on the page.
- Press <kbd>Shift</kbd> + <kbd>Tab</kbd> to navigate in the reverse direction.
- Use <kbd>Alt</kbd> + first letter of menu item to access menu commands.
- For folder navigation, type the first few letters of a file or folder name to jump to it.
- Press <kbd>Ctrl</kbd> + <kbd>K</kbd> (<kbd>⌘</kbd> + <kbd>K</kbd> on macOS) to open the command palette for advanced operations.
